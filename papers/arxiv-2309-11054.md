# Design of Chain-of-Thought in Math Problem Solving

Source: https://arxiv.org/abs/2309.11054
First opened: 2026-09-15

AI-generated from selected main-body sections; verify against the full paper.

## Summary points

- The paper systematically compares natural-language chains of thought with executable program-based chains of thought for mathematical problem solving, including self-describing programs, comment-describing programs, and non-describing programs.
- Experiments on GSM8K, MathQA, and SVAMP evaluate these representations across Python and Wolfram Language using supervised fine-tuning, reward-model reranking, and voting; program-based chains generally outperform natural-language reasoning, and Python generally outperforms Wolfram for the same representation type.
- Self-describing programs usually perform best because meaningful variable names retain natural-language information while supporting executable reasoning and more diverse candidate solutions; combining multiple chain-of-thought types can further improve results.

## Main takeaway

Executable, self-describing Python chains of thought were generally the strongest design for the evaluated math benchmarks, but the evidence is limited to the studied datasets, model scales, training procedures, and program representations.
